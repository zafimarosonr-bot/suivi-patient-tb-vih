Comment sauvegarder

  • Export CSV : idéal pour ouvrir la liste des patients dans Excel ou pour imprimer.
  • Export JSON : sauvegarde complète de toutes les données. À faire régulièrement (hebdomadairement recommandé).
  • Import JSON : restaure les données sur un autre poste ou après une réinstallation.
  • Les fichiers de sauvegarde sont dans le dossier du projet (suivi_patients_*.json).
